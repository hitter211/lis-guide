# LIS 选型评分表（可打印，直接带进评标会）

> 更新于 2026-11-18 ｜ 属于《[中小医院 LIS 选型与上线完整指南](../README.md)》系列
> 用法：3 家供应商各打一遍，80 分以上进短名单。**不要只看总分，看扣分集中在哪一项**——某一项集体低分，说明这个要求市场普遍做不到，你可能要调整预期。

## 二、逐项打分细则

### 1. 业务功能覆盖（20 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| 标本登记与条码 | 3 | 支持条码生成、补打、作废留痕 |
| 标本流转状态跟踪 | 3 | 每个环节有时间戳和操作人，不是只记"已接收" |
| 结果录入与历史比对 | 3 | 支持历史结果叠加、Delta Check 提醒 |
| 审核与电子签名 | 3 | 双层审核，签名可追溯到人 |
| 报告模板自定义 | 3 | 院方自己能改，不用求厂商（现场让供应商演示改一个字段） |
| 危急值识别与闭环 | 3 | 有通知时间、接收人、复读确认记录 |
| 统计与 TAT | 2 | 能出周转时间、工作量、阳性率 |

### 2. 接口与仪器联机（20 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| 现有仪器型号覆盖 | 6 | 逐台核对：**你的**仪器型号有没有接过；没接过的给工期 |
| 协议能力 | 4 | 能说清 ASTM E1394 / HL7 v2.x 的具体实现方式 |
| HIS 接口 | 5 | 申请单下发 + 报告回传双向通；谁改 HIS 侧说清楚 |
| 接口文档 | 3 | 提供接口文档样例（不是"签约后给"） |
| 接口数量与超限单价 | 2 | 报价含几台，超出单价写进合同 |

> ⚠️ 这一项最容易虚高。要求对方**现场打开一个真实接口文档**，不是讲 PPT。

### 3. 评审与合规支撑（15 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| ISO 15189 相关能力 | 4 | 能说出质控、留痕、权限、危急值怎么支撑（说"我们过认证"的直接 0 分） |
| 电子病历 4 级实证项 | 4 | 能对照 01.03.4 五项说清；现场演示医生站内看报告含参考区间 |
| 信创适配现状 | 4 | **具体到数据库/OS 版本 + 有无适配报告**；"支持"两个字不算 |
| 等保三级技术措施 | 3 | 权限分级、审计日志、备份策略可演示 |

### 4. 部署与数据自主（10 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| 部署方式 | 4 | 本地部署 / 私有云，数据不出院 |
| 数据所有权条款 | 3 | 合同明确数据归院方，厂商不得他用 |
| 数据导出能力 | 3 | 能导出结构化数据（不是只有 PDF），格式可读 |

### 5. 实施与服务（15 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| 本地服务能力 | 4 | 本地有团队 / 到场时间承诺（写小时数，不写"尽快"） |
| 实施方法论 | 3 | 有并行运行、验收清单、培训签到与录屏 |
| 响应时效 | 3 | 故障分级 + 响应/解决时限写进合同 |
| 团队稳定性 | 3 | 问：实施这个人走了谁接？（答不出的扣分） |
| 培训 | 2 | 有教材、有录屏，可复用 |

### 6. 商务与合同（10 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| 报价透明度 | 3 | 逐项拆分：软件/接口/实施/培训/维护 |
| 不含项说明 | 2 | 主动说清不含什么（不说的大概率后面加钱） |
| 年维护费比例 | 2 | 15-20% 合理；低于 10% 问清服务边界 |
| 退出机制 | 3 | 数据导出 + 接口文档交付 + 源码托管/escrow 条款 |

### 7. 可持续性（10 分）

| 检查点 | 分值 | 判定标准 |
|---|---|---|
| 产品是否自研 | 3 | 代理的要说明原厂是谁，能不能直接对接原厂 |
| 版本更新频率 | 3 | 近一年有几个版本？改了什么？（拿 release note） |
| 客户可参考性 | 2 | 给 2 家同规模、同区域的案例，允许你打电话问 |
| 公司经营状况 | 2 | 成立年限、社保人数（可查）、是否有同类项目在履约 |

## 三、评标现场必做的 5 个动作

1. **自带数据**：准备 20 条真实检验项目 + 5 个标本，让对方当场录入、出报告。准备好的演示不算。
2. **当场改字段**：让供应商把报告模板里的一个字段改名，看是"5 分钟改完"还是"要提需求排期"。
3. **打开接口文档**：要求现场展示一份真实的接口文档（可以打码）。
4. **问退出机制**：直接问"我们三年后换系统，数据怎么给我"，看表情。
5. **要一个可以打电话的客户**：不接受"客户信息保密"，至少给一个允许你私下问的。

## 四、结果怎么用

| 总分 | 结论 |
|---|---|
| 85+ | 优先谈判 |
| 70-84 | 可谈，但要求对短板书面承诺 |
| 60-69 | 只有在预算极紧时考虑，且必须在合同里补短板条款 |
| <60 | 排除 |

**比总分更重要的是**：如果三家在"信创适配"或"数据导出"上集体低分，说明这是行业普遍短板，你需要在合同里单独约定，而不是换一家就能解决。
